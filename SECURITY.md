# Security Policy

## Supported versions

The project supports the latest patch of each current MCP-revision release line. The project can stop support for an old line after the MCP specification no longer recommends that revision.

## Report a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a public issue for a possible vulnerability. Include the affected module, a small reproduction, the impact, and a safe way to confirm the fix.

A maintainer will acknowledge the report within seven days. The maintainer will coordinate a fix and a disclosure date with the reporter. Do not disclose the issue before that date.
